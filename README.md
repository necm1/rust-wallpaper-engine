## Rust Wallpaper Engine
This is an early experimental project created as a way to get more familiar with Rust.  
At the moment, support is limited to **Windows 11 only**.

---

### Installation

**Prerequisites:**
- Rust (latest stable)
- Windows 11

1. Clone the repository:
   ```bash
   git clone https://github.com/necm1/rust-wallpaper-engine
   ```
2. Navigate into the project directory:
   ```bash
   cd rust-wallpaper-engine
   ```
3. Build and run the project:
   ```bash
   cargo build && cargo run
   ```

---
### Status

The current implementation renders a **solid red background on the primary monitor**.  
Multi-monitor support is still a work in progress, but it may already work with some tweaks.
